Hoe begin ik?

Alle {{ $.Site.Title }}-diensten vereisen mutual TLS én een OAuth-token. Volg de stappen hieronder om te verbinden.

① PKIoverheid-certificaat → ② OAuth token → ③ PRS aanroepen / ③ NVI aanroepen
📜
mTLS
Mutual TLS — vereist voor alles

Gebruik een PKIoverheid-certificaat en test de mTLS-verbinding. Dit is de basis voor alle andere stappen.

Naar mTLS-gids →
🔑
OAuth
Access token ophalen

Haal een RS256-gesigneerd bearer token op via de OAuth-dienst. Vereist: PKIoverheid-certificaat, scope en target_audience.

Naar OAuth-gids →
👤
PRS
Pseudoniemendienst — OPRF

Zet een BSN om naar een deterministisch pseudoniem via het OPRF-protocol. Drie partijen: Client, PRS, Receiver.

Naar PRS-gids →
📑
NVI
Nationale Verwijs Index

Sla FHIR List-resources op en bevraag de NVI om te achterhalen bij welke organisaties een persoon bekend is.

Naar NVI-gids →
