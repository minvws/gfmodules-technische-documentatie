Wat is mTLS?

Bij gewone TLS verifieert alleen de cliënt de server. Bij Mutual TLS (mTLS) verifieert ook de server de cliënt aan de hand van een PKIoverheid-clientcertificaat. Alle {{ $.Site.Title }}-diensten vereisen mTLS: zonder geldig PKIoverheid-certificaat wordt de verbinding al op transportniveau geweigerd.

Wat heb je nodig?

  • PKIoverheid-clientcertificaat (.crt of .pem)
  • Bijbehorende private key (.key)
  • Optioneel: PKCS#12-bundle (.pfx of .p12)

Vereist PKIoverheid-certificaatprofiel

Type: G4 Private TLS Generic Devices Organization Validated Server voor serverauthenticatie (OID 2.16.528.1.1003.1.2.44.15.35.11).

Organisatie-identificatie: Organisatie-identificatienummer (OIN).

PKIoverheid-certificaat gebruiken

Gebruik een PKIoverheid-certificaat voor de GfModules-diensten waarvoor je bent geautoriseerd.

Gebruik voor de integratie je PKIoverheid-clientcertificaat en de bijbehorende private key:

  • client-cert.pem — Je PKIoverheid-clientcertificaat; gebruik hierbij graag de volledige certificaatketen.
  • client-key.pem — De bijbehorende private key.

Gebruik uitsluitend de actuele certificaatketen en trust-instructies die je van de beheerder of certificaatleverancier ontvangt.

Verbinding testen met curl

# Controleer of mTLS-handshake slaagt
{{ range site.Data.services }}{{ if eq .id "oauth" }}curl -v \
  --cert client-cert.pem \
  --key  client-key.pem \
  {{ .base_url }}/.well-known/oauth-authorization-server{{ end }}{{ end }}

Verbinding testen met een PKCS#12-bundle (.pfx / .p12)

# Controleer de mTLS-verbinding met een PKIoverheid G4-testcertificaat
curl 'https://nvi.test.gf.irealisatie.nl/v0.2/api/health' --cert-type P12 --cert pkio_g4_test_cert.pfx:<wachtwoord>

PKCS#12-bundle aanmaken

openssl pkcs12 -export \
  -in    client-cert.pem \
  -inkey client-key.pem \
  -out   client.p12 \
  -name  "gfmodules-client" \
  -passout pass:geheimwachtwoord
Beveilig je private key

Sla de private key nooit op in versiebeheer. Gebruik een secrets-manager (Vault, AWS Secrets Manager, Azure Key Vault) of een OS-sleutelketen.
