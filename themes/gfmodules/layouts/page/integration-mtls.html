Wat is mTLS?

Bij gewone TLS verifieert alleen de cliënt de server. Bij Mutual TLS (mTLS) verifieert ook de server de cliënt aan de hand van een clientcertificaat. Alle {{ $.Site.Params.subtitle }} vereisen daarbij een geldig PKIoverheid-clientcertificaat; zonder geldig certificaat wordt de verbinding al op transportniveau geweigerd.

Wat heb je nodig?

  • PKIoverheid-clientcertificaat met volledige certificaatketen (.crt of .pem)
  • Bijbehorende private key (.key)
  • Optioneel: PKCS#12-bundle (.pfx of .p12)

PKIoverheid-certificaat gebruiken

Gebruik voor de mTLS-verbinding je PKIoverheid-clientcertificaat met volledige certificaatketen en de bijbehorende private key. De bestandsnamen hieronder zijn voorbeelden; vervang ze door de paden naar je eigen bestanden:

  • client-cert.pem — je PKIoverheid-clientcertificaat inclusief de volledige certificaatketen.
  • client-key.pem — de bijbehorende private key.

Verbinding testen met curl

Test de OAuth-endpoint van de dienst waarmee je wilt verbinden.

{{ range site.Data.services }} {{ $svc := . }} {{ with .oauth }}
{{ $svc.name }}
# Controleer of mTLS-handshake slaagt
curl -v \
  --cert client-cert.pem \
  --key  client-key.pem \
  {{ .base_url }}/.well-known/oauth-authorization-server
{{ end }} {{ end }}

Beschikbare endpoints zonder OAuth-token

Voor de endpoints hieronder is geen OAuth-token nodig. Gebruik wel je PKIoverheid-clientcertificaat en private key om de mTLS-verbinding te testen.

{{ range site.Data.services }} {{ $svc := . }} {{ with .oauth }}
{{ $svc.name }}
  • {{ .base_url }}/.well-known/oauth-authorization-server — OAuth-servermetadata
  • {{ .base_url }}/health — health check van de OAuth-service
  • {{ .target_audience }}/health — health check van de API
{{ end }} {{ end }}

Verbinding testen met een PKCS#12-bundle (.pfx / .p12)

# Controleer de mTLS-verbinding met een PKCS#12-bundle
curl https://nvi.proeftuin.gf.irealisatie.nl/v0.2/api/health --cert-type P12 --cert client.p12:<wachtwoord>

PKCS#12-bundle aanmaken

openssl pkcs12 -export \
  -in    client-cert.pem \
  -inkey client-key.pem \
  -out   client.p12 \
  -name  "gfmodules-client" \
  -passout pass:geheimwachtwoord
Beveilig je private key

Sla de private key nooit op in versiebeheer. Gebruik een secrets-manager (Vault, AWS Secrets Manager, Azure Key Vault) of een OS-sleutelketen.
