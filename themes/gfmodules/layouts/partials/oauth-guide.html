OAuth-token voor {{ $svc.name }}

{{ $svc.name }} heeft een eigen OAuth 2.0 Authorization Service. Gebruik dit endpoint om een token voor de {{ $svc.name }} API op te halen. Stuur de vier verplichte formuliervelden grant_type, scope, target_audience en organization_id mee. De voorbeelden hieronder gebruiken mTLS en een voorbeeldscope. Verifieer de verbindings- en autorisatieafspraken altijd bij de aansluiting.

Vervang {{ $oauth.url_placeholder }} door het afgesproken serveradres van de OAuth-service, inclusief https:// en zonder afsluitende slash.

Token {{ $oauth.url_placeholder }}{{ $oauth.base_path }}/token

Token ophalen

Dit integratievoorbeeld gebruikt grant_type=client_credentials en een PKIoverheid-certificaat. Stem de clientauthenticatie en de te gebruiken grant- en scopewaarden af bij de aansluiting.

Vul {{ $oauth.url_placeholder }} in met het afgesproken OAuth-serveradres voordat je de cURL-, PHP- of Python-voorbeelden uitvoert. Vervang {{ $oauth.target_audience }} door de afgesproken identificatie van de doelservice. 

curl -s -X POST \
  --cert client-cert.pem \
  --key  client-key.pem \
  -H "Content-Type: application/x-www-form-urlencoded" \
  --data-urlencode "grant_type=client_credentials" \
  --data-urlencode "scope={{ $oauth.default_scope }}" \
  --data-urlencode "target_audience={{ $oauth.target_audience }}" \
  --data-urlencode "organization_id={{ $oauth.organization_id_example }}" \
{{ if $oauth.source_id_scopes }}  --data-urlencode "source_id={{ $oauth.source_id_example }}" \
{{ end }}  "{{ $oauth.url_placeholder }}{{ $oauth.base_path }}/token" \
  | python3 -m json.tool
[$status, $body] = curlRequest($certFile, $keyFile, '{{ $oauth.url_placeholder }}{{ $oauth.base_path }}/token', [
    CURLOPT_POST       => true,
    CURLOPT_POSTFIELDS => http_build_query([
        'grant_type'        => 'client_credentials',
        'scope'             => '{{ $oauth.default_scope }}',
        'target_audience'   => '{{ $oauth.target_audience }}',
        'organization_id'   => '{{ $oauth.organization_id_example }}',
{{ if $oauth.source_id_scopes }}        'source_id'         => '{{ $oauth.source_id_example }}',
{{ end }}    ]),
    CURLOPT_HTTPHEADER => ['Content-Type: application/x-www-form-urlencoded'],
]);
import requests

session = requests.Session()
session.cert = ("client-cert.pem", "client-key.pem")

resp = session.post(
    "{{ $oauth.url_placeholder }}{{ $oauth.base_path }}/token",
    data={
        "grant_type":      "client_credentials",
        "scope":           "{{ $oauth.default_scope }}",
        "target_audience": "{{ $oauth.target_audience }}",
        "organization_id": "{{ $oauth.organization_id_example }}",
{{ if $oauth.source_id_scopes }}        "source_id":       "{{ $oauth.source_id_example }}",
{{ end }}    },
)

Leg bij de aansluiting vast hoe je de tokenresponse verwerkt en welke tokenlevensduur en welk refreshbeleid gelden. Gebruik daarbij de OAuth-metadata en de aansluitafspraken.
