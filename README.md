# Generieke Functies Technical Documentation

This repository contains the technical documentation for Generieke Functies.

## Local preview

Install Hugo by following the official docs:
https://gohugo.io/installation/

To preview the documentation while editing, run from the repository root:

```bash
hugo server
```

Hugo will print a local URL (usually `http://localhost:1313/gfmodules-technische-documentatie/`).

## Publishing

Documentation is published through GitHub Actions when changes are pushed to `main`.
